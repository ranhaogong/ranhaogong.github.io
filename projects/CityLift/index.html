Abstract

Generating urban scenes as individual 3D assets enables flexible scene editing and provides geometry for simulation and urban world modeling. CityLift addresses this task from a single image and building instance masks, generating a separate mesh for each building within a shared scene.

Our framework first generates an urban scaffold that jointly represents scene layout and coarse building structure. Generative spatial inheritance then transfers coarse geometric support and scene features into dedicated local building volumes. Conditioned building regeneration produces detailed local structure, which is converted to meshes and assembled in the scene through the inherited spatial mapping. We also introduce CityLift-5K, a collection of 4,997 scenes pairing images and instance masks with building geometry and scene placement.
